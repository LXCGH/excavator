# 2026-03-17 Dev - 创建房间按钮无响应修复

## 问题现象

- 在“创建游戏”弹窗里点击“创建并进入房间”，界面没有明显反馈，用户感知为按钮无响应。

## 根因分析

- 前端在 `socket` 未连接时，创建/加入逻辑直接 `return`。
- 错误提示写在游戏页提示区域，而不是当前弹窗，用户在弹窗里看不到提示。
- 弹窗事件每次打开都会重复绑定，存在潜在重复触发风险。

## 修复内容

### 1. 增加“连接等待 + 自动继续”机制

- 当点击创建或加入时，如果 `socket` 还没连上：
  - 记录待执行动作（创建或加入目标房间码）
  - 按钮进入“连接中...”状态
  - 自动触发 `socket.connect()`
- 一旦连接成功，自动继续执行之前的创建或加入动作。

### 2. 弹窗按钮连接态管理

- 增加 `setModalConnectionState(connected)`：
  - `创建并进入房间`
  - `通过房间码加入`
  - `刷新列表`
- 以上按钮会随连接状态启停，避免“点击了但没反应”的体验。

### 3. 防止重复绑定弹窗事件

- 增加 `modalEventsBound` 标记，弹窗事件只绑定一次。

### 4. 复用现有 socket 实例

- `connectSocket()` 先检测已有实例，避免重复创建 socket 连接对象。

## 验证结果

- 前端执行 `npm run build` 通过。
- 现在在连接尚未就绪时点击创建，会显示“连接中...”，连接成功后自动创建并进入房间。
