# 2026-03-17 Dev - 创建弹窗连接中状态修复

## 问题现象

- “创建游戏”弹窗里一直显示“连接中...”，无法恢复成“创建并进入房间”。

## 根因

- 弹窗打开时先强制设置了未连接状态。
- 当已有 socket 且已连接时，`connectSocket()` 会直接返回，未把按钮状态切回已连接。

## 修复

- `showStartModal()` 改为根据 `socket.connected` 设置初始连接态，而不是固定置为未连接。
- `connectSocket()` 在复用已有 socket 且已连接时，显式调用 `setModalConnectionState(true)`。

## 验证

- 前端执行 `npm run build` 通过。
