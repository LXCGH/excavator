# 2026-03-17 DevLog - 你画我猜词库扩容与去重抽词

## 背景
- 用户反馈词库偏少，重复率高，影响持续游玩体验。

## 改动内容
- 新增独立词库文件 `draw-guess.words.ts`，从原有小词库扩容到 **253** 个词条。
- 词库按类别组织（动物、水果、蔬菜、美食、交通工具、日用品、家电、乐器、运动、职业、自然、植物、场景、节日、文具、服饰），便于后续继续追加。
- 抽词策略升级：
  - 新增房间内 `usedWords` 追踪，本局内优先抽取未使用词条，减少重复。
  - 当本局词条用完后自动清空已使用集合并继续抽取（自动“洗牌”）。
  - 继续避免与上一题完全相同，并尽量避免连续同类别，提升题目变化感。

## 影响文件
- `backend/src/draw-guess/draw-guess.words.ts`
- `backend/src/draw-guess/draw-guess.service.ts`

## 验证
- 后端构建通过：`npm run build`（backend）
