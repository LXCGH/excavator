# 2026-03-17 Dev - 你画我猜双端画面比例一致性修复

## 问题现象

- 两端看到的同一笔画大小和形状不一致，出现明显拉伸。

## 根因

- 画布在不同设备/窗口下容器宽高比不同，归一化坐标按各端本地宽高反算，导致纵横比不一致时出现变形。
- 从房间页切到对战页时，画布尺寸有机会沿用旧值，进一步放大误差。

## 修复内容

### 1. 统一画布显示比例

- 画布容器固定为 `16:10`（移动端 `4:3`），减少两端比例差异导致的形变。

### 2. 视图切换时强制重算画布尺寸

- 从房间页进入对战页时，在下一帧执行 `resizeCanvas()`，确保内部像素尺寸和当前显示尺寸一致。

### 3. 绘制过程增加尺寸同步保护

- 在开始绘制和移动绘制前增加 `ensureCanvasResolution()`。
- 当检测到内部像素尺寸与当前显示尺寸不一致时，自动重算，避免“显示尺寸变了但内部尺寸没变”。

## 验证

- 前端执行 `npm run build` 通过。
