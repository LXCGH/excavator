# 2026-03-17 Dev - 你画我猜撤回无响应兼容修复

## 问题现象

- 点击撤回后几乎看不到变化，体感像“没反应”。

## 根因

- 历史会话里存在未携带 `strokeId` 的旧笔画数据。
- 撤回逻辑在无 `strokeId` 场景下只能删掉最后一个小线段，视觉变化非常小。

## 修复内容

### 后端撤回兼容升级

- 若存在 `strokeId`：按最后一笔的 `strokeId` 删除整笔轨迹。
- 若不存在 `strokeId`（旧客户端/旧数据）：
  - 按“连续轨迹 + 同画笔参数（颜色、粗细、橡皮状态）”回溯并删除整笔。
  - 不再只删除单个分段。

## 影响文件

- `backend/src/draw-guess/draw-guess.service.ts`

## 验证

- `backend`: `npm run build` 通过
- `web`: `npm run build` 通过
