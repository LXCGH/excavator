# 2026-03-17 Dev - 你画我猜房间列表不刷新修复

## 问题现象

- 房主创建房间后，其他玩家进入“加入游戏”页面时，房间列表经常不刷新或看不到新房间。

## 根因分析

- 房间列表主要依赖“进入加入页后主动拉取一次”，缺少房间状态变化后的实时推送。
- Socket 默认连接使用固定 `:3000`，在跨设备或代理场景下容易出现连接不稳定，导致列表拉取失败。

## 修复内容

### 1. Socket 默认改为同源连接

- 前端 `DrawGuessGame` 中 `getSocketUrl` 逻辑调整为：
  - 配置了 `VITE_API_BASE_URL` 时使用配置值
  - 未配置时使用 `window.location.origin`
- 这样可以复用前端代理和部署反代，避免玩家设备直连 `:3000` 带来的不确定性。

### 2. 后端增加房间列表广播

- 在网关中增加 `broadcastRoomList()`，统一向所有客户端推送当前可加入房间列表。
- 在以下房间变更场景触发广播：
  - 客户端连接
  - 创建房间
  - 加入房间
  - 离开房间
  - 断开连接
  - 房主开始游戏（房间应从可加入列表中移除）
  - 切房间时离开旧房间

## 验证结果

- `backend` 执行 `npm run build` 通过。
- `web` 执行 `npm run build` 通过。
- 现在加入页会在房间变化时自动更新列表，不再依赖手动刷新按钮。
