# 2026-03-17 Dev - 你画我猜底部工具面板固定样式修正

## 问题现象

- 画布下方出现大块空白区域，底部工具面板位置不稳定。

## 根因

- 画布区使用了拉伸布局，导致 `draw-board-stack` 被过度撑高。
- 工具面板处于普通文档流，滚动和布局变化时不稳定。

## 修复内容

- `draw-play-area` 去掉强制拉伸，改为顶部对齐。
- `draw-board-stack` 改为 `auto auto` 行布局，避免多余空白。
- `draw-tools-card` 改为 `position: sticky` 固定在底部（`bottom: 8px`），并提高层级与背景稳定性。

## 影响文件

- `web/style.css`

## 验证

- `web`: `npm run build` 通过
