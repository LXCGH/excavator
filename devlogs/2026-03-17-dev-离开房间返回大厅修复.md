# 2026-03-17 Dev - 离开房间返回大厅修复

## 问题现象

- 在“你画我猜”里点击“离开房间”后，页面停留在房间空状态（房间未加入），没有回到大厅。

## 根因

- `leaveRoom()` 只发了 `roomLeave` 并重置本地房间 UI，没有触发大厅返回流程。
- 大厅返回逻辑依赖 `drawGuess:cancel` 事件，但离开房间时未触发该事件。

## 修复

- `leaveRoom()` 改为：
  - 先通知后端 `drawGuess:roomLeave`
  - 再触发 `window.dispatchEvent(new CustomEvent('drawGuess:cancel'))`
- 这样会走统一的大厅返回流程，销毁当前游戏实例并显示大厅页。

## 验证

- 前端执行 `npm run build` 通过。
