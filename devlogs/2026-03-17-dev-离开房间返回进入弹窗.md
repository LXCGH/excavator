# 2026-03-17 Dev - 离开房间返回进入弹窗

## 需求调整

- 离开房间后，不直接返回游戏大厅首页。
- 需要回到“你画我猜”进入弹窗（创建游戏 / 加入游戏 / 取消）。

## 实现

- 调整 `DrawGuessGame.leaveRoom()`：
  - 保留 `drawGuess:roomLeave` 通知后端离房。
  - 本地重置房间状态和画布。
  - 显示 `draw-guess-modal` 并隐藏创建/加入子表单，回到入口弹窗状态。
  - 根据当前 socket 连接状态刷新弹窗按钮状态，必要时自动重连。

## 验证

- 前端 `npm run build` 通过。
