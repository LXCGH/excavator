# 2026-03-17 Dev - 你画我猜画布底部工具面板改造

## 需求

- 将画布相关操作统一放到画布底部，形成一个集中工具面板。

## 修改内容

### 1. 结构调整（HTML）

- 移除画布上方工具条位置。
- 在画布区域下方新增统一底部工具面板（保留原有交互 ID）：
  - 颜色选择
  - 画笔粗细、橡皮大小
  - 画笔/橡皮切换
  - 撤回、清空画布
  - 当前工具状态显示
- 侧边栏中的原“撤回/清空”卡片移除，避免工具分散。

### 2. 样式调整（CSS）

- 画布主区改为 `draw-board-stack`：上方画布、下方工具面板。
- `draw-board-panel` 改为纵向容器，保证工具面板固定在画布底部区域。
- 新增底部工具条样式 `draw-toolbar-bottom` 与 `draw-tools-card` 间距/对齐优化。
- 保持移动端下的响应式堆叠行为。

## 影响文件

- `web/index.html`
- `web/style.css`

## 验证

- `web`: `npm run build` 通过
