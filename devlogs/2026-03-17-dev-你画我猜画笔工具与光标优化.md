# 2026-03-17 Dev - 你画我猜画笔工具与光标优化

## 问题现象

- 画笔颜色缺少明确反馈，用户难以确认当前颜色。
- 只有单一粗细控制，橡皮擦无法独立调整大小。
- 画布光标始终是十字，缺少画笔/橡皮的模式区分。

## 修复内容

### 1. 工具栏状态完善

- 接入并同步以下状态控件：
  - 当前工具（画笔/橡皮）
  - 当前粗细
  - 当前颜色指示点
- 画笔/橡皮按钮增加互斥高亮，切换模式时实时更新。

### 2. 画笔与橡皮独立粗细

- 保留画笔粗细滑杆（`#draw-brush-size`）。
- 新增橡皮大小滑杆（`#draw-eraser-size`）。
- 实际下笔时按当前模式分别使用 `brushSize` 或 `eraserSize`。

### 3. 绘制与擦除逻辑优化

- 绘制时按 `stroke.color` 渲染，增加颜色兜底，避免异常值导致无色笔画。
- 橡皮模式改为 `destination-out` 合成擦除，更符合真实橡皮表现。

### 4. 光标样式优化

- 画笔模式使用画笔形状光标（`cursor-brush`）。
- 橡皮模式使用橡皮形状光标（`cursor-eraser`）。
- 工具切换时同步更新画布光标 class。

### 5. 可操作性联动

- 只有当前画手且处于 `drawing` 阶段时，允许操作画笔/橡皮、颜色与粗细控件。
- 非可绘制状态下自动禁用相关控件，避免误操作。

## 影响文件

- `web/src/DrawGuessGame.js`
- `web/style.css`
- `web/index.html`（已存在控件结构，本次脚本与样式完成接线）
