# 2026-03-17 Dev - 你画我猜终局机制设计落地

## 背景

- 你画我猜当前可无限开回合，缺少“本局结束”与结算规则，体验不完整。

## 设计与实现

### 1. 对战终局规则

- 每局默认最多 `6` 回合（`DEFAULT_MATCH_ROUNDS`）。
- 达到回合上限后自动进入终局：
  - 标记 `isGameOver = true`
  - 计算最高分玩家（支持并列）
  - 写入 `winnerPlayerIds`
  - 记录系统结算日志

### 2. 再来一局机制

- 新增 socket 事件：`drawGuess:matchReset`
- 仅房主可操作，且仅在终局状态可触发
- 重置内容：
  - 回合数、分数、准备状态、画布、当前题目、计时状态
  - 返回到“等待准备”的可开局状态

### 3. 前端交互适配

- “开始游戏/下一回合”按钮改为动态行为：
  - 普通阶段：开始新回合
  - 终局阶段（房主）：显示“再来一局”并触发重置
- 终局展示：
  - 显示“本局已结束（共 N 回合）”
  - 显示冠军名称与分数
  - 玩家端显示等待房主重置提示

### 4. 边界状态修复

- 对战中若房间人数降到 1 人，自动回到可重新组局状态（避免房间卡死）。
